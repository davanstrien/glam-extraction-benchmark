# NLS API batch: 2026-09-15

This optional recipe generates format-2 submissions. Scoring does not require HF
Inference Providers or this script. It reuses the reference producer's prompt,
JPEG conversion and scoring helpers, and leaves its original nullable JSON Schema
intact. Only the supplied image, target schema and task instructions are sent;
expected outputs remain local for scoring.

Dataset: `small-models-for-glam/glam-extraction-benchmark`, revision
`ecc9c02582f933ca89b73e6751e4ed76888cb24d`, config `nls-index-cards`, split `test`,
98 cards. The source NLS cards and schema are public CC0 material; the benchmark
export and results bucket are private during development.

| Label | HF provider | Output cap | Extra request settings |
|---|---|---:|---|
| Qwen3.5-9B | DeepInfra | 1,600 | `chat_template_kwargs.enable_thinking=false` |
| Qwen3.8-27B | Novita | 1,600 | `chat_template_kwargs.enable_thinking=false` |
| Qwen3-VL-235B | DeepInfra | 1,600 | none |
| GLM-5.3-Flash | DeepInfra | 4,096 | `reasoning_effort=low` |

All runs use temperature 0 and unconstrained JSON generation. GLM gets additional
output room for reasoning; this is an economical extraction setting, not a
reproduction of its model card's maximum-reasoning benchmarks. The provider's
reported reasoning usage and finish reason are retained so requested settings can
be distinguished from observed behavior.

```bash
uv run examples/inference/api_batch.py --model Qwen3.5-9B --limit 2 --budget-usd 0.6
uv run examples/inference/api_batch.py --model Qwen3.5-9B --resume --budget-usd 0.6
uv run examples/inference/api_batch.py --model Qwen3.8-27B --limit 2 --budget-usd 0.9
```

The actual run used the pre-existing UV-created Python 3.11 environment at
`/private/tmp/glam-contract-env/bin/python` in place of `uv run`, and
`HF_HUB_DISABLE_PROGRESS_BARS=1` after the first two smoke runs. Exact installed
dependency versions are recorded in every result's `run.dependencies` block.
Two-card smoke checks passed for all four models before resuming; their predictions
are retained, so each complete run makes 98 successful requests without paying
again for the smoke cards. Transport errors stop execution for inspection rather
than retrying invisibly. Resume keeps completed items and the original settings.

Local files are under `results/nls-index-cards/2026-09-15-nullable-v1/` (ignored by
Git). Every card is checkpointed locally, with bucket uploads every ten cards and
at each deliberate pause/completion:

```text
hf://buckets/small-models-for-glam/glam-extraction-results/
  nls-index-cards/2026-09-15-nullable-v1/<label>.json.partial
  nls-index-cards/2026-09-15-nullable-v1/<label>.json
```

The `.json` file is canonical only after completion and submission validation.
A prior `.partial` bucket checkpoint may remain for diagnosis; it is not a final
submission. Token usage and provider response IDs are stored per card. Cost is an
estimate from the recorded input/output prices; provider-returned usage may also
include its own estimate. The script reserves room before each request and pauses
before its model budget is exhausted. This is not an account-level billing cap.
The four model budgets total $2.70, within the allocated $3 API budget.

The Hub model revision is a timestamped observation of model-repo `main`; an API
does not prove which weight revision it served. These recipe submissions therefore
use `produced_by: {producer: other, attested: false}`.
